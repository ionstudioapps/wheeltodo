## Database Schema

### `user_settings`
One row per user. Created on first login.

| Column | Type | Default | Notes |
|--------|------|---------|-------|
| `user_id` | uuid PK | — | FK → auth.users |
| `is_premium` | bool | false | |
| `daily_goal` | int | 3 | |
| `default_timer_minutes` | int | 25 | |
| `rest_goal_tier` | text | 'standard' | easy \| standard \| dedicated |
| `theme` | text | 'warm-start' | warm-start \| slow-down \| light-a11y \| dark-a11y |
| `categories` | text[] | ['Work','Personal','Learning','Health'] | |
| `spin_count` | int | 0 | total lifetime spins |
| `updated_at` | timestamptz | now() | |

### `tasks`
Active task list per user.

| Column | Type | Notes |
|--------|------|-------|
| `id` | text PK | |
| `user_id` | uuid | FK → auth.users |
| `name` | text | |
| `minutes` | int | estimated duration |
| `color` | text | hex |
| `icon` | text | emoji |
| `category` | text | nullable |
| `context` | text | background captured from voice input; seeded into subtask generation |
| `parent_task_id` | text | set on subtasks generated by break-task |
| `calendar_event_id` | text | Google Calendar event id after push |
| `position` | int | display order |

### `completed_tasks`
Append-only log of finished tasks.

| Column | Type | Notes |
|--------|------|-------|
| `id` | text PK | |
| `user_id` | uuid | |
| `task_id` | text | original task id |
| `task_name` | text | snapshot at completion |
| `color`, `icon`, `category` | text | snapshots |
| `minutes_estimated` | int | |
| `minutes_actual` | int | |
| `completed_at` | timestamptz | |

### `rest_tasks`
Custom rest activities (presets are hardcoded client-side).

| Column | Type | Notes |
|--------|------|-------|
| `id` | text PK | |
| `user_id` | uuid | |
| `name` | text | |
| `duration_minutes` | int | |
| `is_preset` | bool | always false for user rows |
| `category` | text | physical \| mental \| social \| nourishment \| custom |

### `rest_days`
One row per user per calendar date.

| Column | Type | Notes |
|--------|------|-------|
| `user_id` | uuid | |
| `date` | date | |
| `is_complete` | bool | |
| `partial_pct` | int | 0–100; null when fully complete |

### `calendar_connections`
OAuth tokens for Google Calendar per user.

| Column | Type | Notes |
|--------|------|-------|
| `user_id` | uuid | |
| `provider` | text | 'google' |
| `access_token` | text | refreshed automatically |
| `refresh_token` | text | nullable |
| `token_expires_at` | timestamptz | |
| `calendar_id` | text | 'primary' by default |
| `last_synced_at` | timestamptz | updated after each pull |

All tables have **Row Level Security** enabled. Each user can only read/write their own rows.

## Migrations

| File | What it does |
|------|-------------|
| `20260518085315_initial_schema.sql` | Core tables: user_settings, tasks, completed_tasks, rest_tasks |
| `20260524000000_sync_fields.sql` | Adds theme, categories, spin_count → user_settings; parent_task_id → tasks; creates rest_days |
| `20260526000000_calendar.sql` | Creates calendar_connections; adds calendar_event_id → tasks |
| `20260526000001_task_context.sql` | Adds context → tasks |

### Applying migrations

```bash
# Push all pending migrations to the linked remote project
supabase db push --linked --yes

# Check what's pending
supabase migration list
```

## Edge Functions

See [`functions/README.md`](./functions/README.md) for full API docs.

### Deploying

```bash
# Deploy a single function
supabase functions deploy <function-name>

# Deploy calendar-connect (needs --no-verify-jwt for the OAuth callback path)
supabase functions deploy calendar-connect --no-verify-jwt
supabase functions deploy calendar-pull --no-verify-jwt

# Deploy all at once
for fn in break-task voice-tasks suggest-category calendar-push; do
  supabase functions deploy $fn
done
```

### Required secrets

Set these in **Supabase Dashboard → Project Settings → Edge Functions**:

| Secret | Required by |
|--------|------------|
| `ANTHROPIC_API_KEY` | break-task, voice-tasks, suggest-category |
| `GOOGLE_CLIENT_ID` | calendar-connect |
| `GOOGLE_CLIENT_SECRET` | calendar-connect, calendar-push, calendar-pull (token refresh) |
| `APP_URL` | calendar-connect (post-OAuth redirect target) |
